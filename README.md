# Console Blackjack Game in C#

A complete C# Console Application implementation of the classic Blackjack card game. 
This project features realistic game logic including card splitting, doubling down, and insurance options.

## Features
- **Standard Card Dealing Sequence:** Dealer and player draw cards following standard casino sequence (Player -> Dealer -> Player -> Dealer).
- **Hand Splitting (Split):** Split pairs into two separate hands (including split Aces logic).
- **Double Down:** Double your bet on the initial two cards and receive exactly one extra card.
- **Insurance:** Buy insurance when the dealer's visible card is an Ace.
- **Ace Handling:** Dynamic Ace value evaluation (11 or 1) to prevent busting automatically.
- **Play Again Loop:** Easy replay mechanism to play multiple rounds.
